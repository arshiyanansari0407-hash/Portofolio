# Portofolio Web — [Arshiyan / arshiyanansari0407-hash]

Welcome to my personal web portfolio! 🌐
Built with React + Vite, this is a showcase of projects, skills, and works that I want to share.


##  Project Structure

- `public/` — - static files (favicon, assets, etc.)
- `src/` — main React code (components, utilities, etc.) 
- `index.html` — web page entry point  
- `package.json` & `package-lock.json` — dependency management and scripts
- `vite.config.js` — build configuration and Vite dev server  
- `eslint.config.js` — linting rules to keep code clean and consistent 

##  Key Features

- Built with **React + Vite** – lightweight, fast reload, and optimal build performance
- **ESLint** configured to keep coding style neat  
- Modular structure ready for scaling – can add "About", "Projects", etc. pages

##  How to Run

1. Clone repository ini:
```bash
git clone https://github.com/arshiyanansari0407-hash/Portofolio.git
cd portofolio
````

2. Install dependencies:
```bash
npm install
````

3. 3. Run the local server with hot reload:
```bash
npm run dev
````

4. Build for production
```bash
npm run build
````
